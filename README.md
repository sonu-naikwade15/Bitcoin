# Bitcoin price forecasting
Overview:This project focuses on forecasting Bitcoin prices using Machine Learning. Historical Bitcoin data is analyzed and a Linear Regression model is used as the main algorithm to predict Bitcoin prices.

Objectives:
Analyze historical Bitcoin price data.
Perform data preprocessing and visualization.
Identify price trends using SMA and EMA.
Split the data into training and testing sets.
Build a Linear Regression model.
Evaluate model performance using regression metrics.

Technologies used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Google Colab / Jupyter Notebook

Evaluation Metrics:
MAE – Mean Absolute Error
MSE – Mean Squared Error
RMSE – Root Mean Squared Error
R² Score

Results:
The Linear Regression model was trained using historical Bitcoin data and tested on unseen data. The model generated predicted Bitcoin prices and its performance was evaluated using MAE, MSE, RMSE, and R² Score. The actual and predicted prices were also compared to understand the model's performance.
